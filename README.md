# Urban Harvest - Admin Dashboard

A responsive admin dashboard for a fictional food delivery platform built with **React**, **Redux Toolkit**, and **React Router**. This project was built as part of a UI/UX Developer Fresher Assignment.

## Features

-  **Login Page** — Email/password fields, "Remember Me" option, simple validation
- **Dashboard** — Stat cards (Total Orders, Revenue, Active Users, Pending Deliveries) and a recent orders table
- **Product Management** — Product cards with search, status filter, add product modal, toggle status, delete

## tool and techs used

- **React 18** (with Vite)
- **Redux Toolkit** + **React Redux**
- **React Router v6**
- **Plain CSS** 



##  Setup Instructions

### 1. Install dependencies

Open the project folder in your terminal and run:

```bash
npm install
```

This installs React, Redux Toolkit, React Router, and Vite.

### 2. Start the development server

```bash
npm run dev
```

Open your browser at the URL shown in the terminal (usually `http://localhost:5173`).
